## 📖 使用说明
- 一个版本一个提交，下载对应版本即可  
- **仅作为学习用途**  
- 功能：
  - 导出正在运行的微信进程 Key  
  - 自动解密微信数据库文件  
  - 配合 [wxrobot_dbkey](https://github.com/msfm2018/wxrobot_dbkey) 项目解析数据库文件
